# ⚽ 足球人生模拟器

AI 叙事主导的足球生涯模拟 Web 应用：扮演 2007 年出生的中国青训球员，从 16 岁踢到 40 岁，体验完整球员生涯（或转型教练）。

## ✨ 功能

- **AI 小说级叙事**：每个决策点由 LLM 生成细腻的叙事文本与选项（OpenAI 兼容接口：DeepSeek / OpenAI / 硅基流动等）
- **FIFA 式属性系统**：PAC/SHO/PAS/DRI/DEF/PHY + 门将专属 GK + 隐藏属性（花式/逆足星级），0-99
- **位置加权 OVR**：10 个位置各有权重表，实时计算总评与身价（欧元）
- **完整生涯**：每赛季 8 个决策点（夏窗→季前备战→上半程×2→冬窗→下半程×2→赛季末），40 岁触发退役/转教练抉择
- **真实世界模拟**：16 个联赛 306 队（中超/中甲 + 五大联赛及次级 + 荷甲/葡超）、泊松分布比赛、升降级、转会报价
- **国家队线**：U17→U20→U23→国足征召判定
- **硬约束**：18 岁前 OVR ≤ 80、身价 ≤ 8000 万欧元（引擎强制）
- **SVG 雷达图面板**：属性可视化，零前端依赖

## 🚀 快速开始

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 http://127.0.0.1:8000

1. **设置页**：填写 API Key（DeepSeek/OpenAI/硅基流动等，OpenAI 兼容接口；不填无法游玩）
2. **建档页**：填写姓名、出生地区、身高体重、惯用脚、位置、青训机构（鲁能/恒大/根宝/绿城/国安/万达留洋）
3. **主界面**：阅读叙事 → 点击选项 → 查看属性雷达图与身价变化

存档自动保存至 `saves/latest.json`，刷新页面可继续。

## 🏗️ 架构

```
浏览器（原生 JS 单页，零构建）
  ↕ REST API
FastAPI（app/）
  ├─ api/      建档/决策/状态/配置/世界查询
  └─ narrator/ LLM 客户端 + 提示词 + JSON 校验（防幻觉：数值只由引擎结算）
  ↕ 函数调用
Python 引擎（engine/）
  attributes(属性/OVR) value(身价) development(成长) player(档案)
  season(赛季状态机) world(16联赛模拟) market(转会) national(国家队)
  decision(决策骨架) coach(教练) save(存档)
```

**防幻觉设计**：决策选项的数值效果全部由引擎预生成（`engine/decision.py`、`engine/season.py`），LLM 只负责叙事文本与选项文案，无法篡改任何数值。

## 📁 数据

- `data/clubs.csv`：16 联赛 306 队
- `data/players.csv`：真实球员数据集（`python scripts/fetch_dataset.py` 下载转换，失败时使用内置精简名单）
- `data/players_cn.csv`：球星中文名映射
