# 足球人生模拟器 · 设计文档（Web 版）

> 版本：v2.0 ｜ 日期：2026-08-09 ｜ 状态：待审查
> 类型：AI 叙事主导的交互式足球生涯模拟 Web 应用（FastAPI + 原生 JS + Python 引擎 + LLM 叙事）

---

## 1. 概述

玩家扮演一名 **2007 年出生的中国青训球员**，从 2023 年夏天（16 岁）入营开始，由 **LLM（用户自配 API Key，OpenAI 兼容接口）** 以小说笔触推动职业生涯。玩家在浏览器网页内完成全部游戏流程：看叙事、选选项、看面板。每赛季 8-10 个决策点，直至 40 岁触发退役 / 转教练抉择。

**核心定位变更（v2.0）**：
- 由"对话式游戏 + 只读看板"升级为 **完整 Web 应用**：网页内完成建档、叙事、决策、面板展示全部流程
- AI 叙事由 **用户提供的 API Key**（OpenAI 兼容接口：DeepSeek / OpenAI / 硅基流动等）驱动
- **未配置 API Key 无法游玩**（不做模板降级，AI 叙事为硬性要求）
- 引擎负责数值与世界模拟，LLM 只负责叙事与选项文案——**数值永远由引擎结算，LLM 不可篡改**

**硬性约束（引擎强制）**：
- 18 岁前 OVR ≤ 80
- 18 岁前身价 ≤ 8000 万欧元
- 属性区间 0-99（整数）
- 40 岁生日当季末触发退役抉择（退役 / 继续征战 / 转教练）

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│  浏览器（原生 JS 单页，零构建）                                    │
│  · 叙事流 + 决策按钮   · 属性面板/雷达图   · 积分榜/转会市场      │
│  · 设置页（API Key 配置）  · 建档页                               │
└───────────────────────────┬─────────────────────────────────────┘
                            │ REST API（JSON）
┌───────────────────────────▼─────────────────────────────────────┐
│  FastAPI 后端（app/）                                             │
│  ├─ api/        REST 路由：建档/决策/状态/设置/存档               │
│  ├─ narrator/   LLM 服务层：OpenAI 兼容客户端、提示词、JSON 校验  │
│  │              · 决策骨架由引擎生成 → LLM 文学化包装             │
│  │              · 输出强制 JSON 校验，数值变更必须通过引擎        │
│  └─ 引擎调用（engine 模块函数）                                   │
└───────────────────────────┬─────────────────────────────────────┘
                            │ 函数调用
┌───────────────────────────▼─────────────────────────────────────┐
│  Python 引擎（engine/，纯逻辑，无 UI）                            │
│  · 属性模型/OVR/身价   · 成长衰退曲线   · 世界模拟（16联赛306队） │
│  · 转会市场   · 合同系统   · 国家队线   · 教练生涯               │
│  · 存档读写（saves/*.json）   · 决策骨架生成（含合法数值效果）    │
└──────────────────────────────────────────────────────────────────┘
```

**一条决策的完整链路**：
1. 用户点击选项按钮 → 前端 POST `/api/game/decision`
2. 后端将 `{选项效果}` 交给引擎结算（属性/状态/身价变化）
3. 引擎推进世界（若到窗/季末）并生成**下一决策骨架**（事件 + N 个选项，每个选项带引擎预生成的合法数值效果）
4. 后端把「存档状态摘要 + 生涯历史摘要 + 决策骨架」发给 LLM
5. LLM 返回 `{narrative, options:[{label, hint}]}`（纯文案，无数值）
6. 后端合并骨架数值与 LLM 文案 → 存档 → 返回前端渲染

> **防幻觉原则**：LLM 的输出只有叙事文本和选项文案；所有选项的后果是引擎预生成的合法值（属性点、状态系数、身价浮动等），LLM 无法引入非法数值。LLM 请求失败 → 返回错误提示（不伪造结果），用户可重试。

全部属性 **0-99 整数**。

### 4.1 六大项（field attributes）

| DEF 防守 | 防守意识 Def. Awareness、拦截 Interceptions、头球精度 Heading、立定抢断 Standing Tackle、滑铲 Sliding Tackle |

### 4.3 隐藏 / 附加信息

## 5. OVR 计算与位置权重

OVR = Σ(子属性 × 权重) / Σ(权重)，四舍五入。

| 位置 | 核心分项与权重 |
|------|----------------|
| ST 中锋 | 站位30 射术25 沉着15 反应10 加速5 射门力量5 力量5 跳跃5 |
| LW/RW 边锋 | 加速25 敏捷15 盘带15 控球10 平衡10 传中10 沉着10 远射5 |
| CAM 前腰 | 短传20 视野20 沉着20 反应10 远射10 控球10 盘带5 射术5 |
| CM 中场 | 短传20 视野15 沉着15 反应10 耐力10 拦截10 控球10 远射5 防守意识5 |
| CDM 后腰 | 拦截20 防守意识20 力量15 耐力15 短传10 侵略性10 沉着10 |
| LB/RB 边后卫 | 速度20 耐力15 拦截15 立定抢断15 传中15 防守意识10 加速10 |
| CB 中后卫 | 防守意识25 拦截20 力量15 跳跃15 反应10 立定抢断10 速度5 |

## 6. 身价模型（欧元）

```
身价 = 基础身价(OVR) × 年龄系数 × 位置系数 × 联赛系数 × 合同系数 × 状态系数
```

### 6.1 基础身价（中值曲线）

| OVR | 基础身价（欧元） |
|-----|------------------|
| 55 | 9 万 |
| 60 | 30 万 |
| 65 | 100 万 |
| 70 | 330 万 |
| 75 | 1100 万 |
| 80 | 3600 万 |
| 85 | 1.2 亿 |
| 90 | 2.0 亿（放缓修正后） |

**公式**：
```
基础身价 = 300,000 × 1.27^(OVR-60)          （OVR ≤ 85）
基础身价 = 1.19亿 × 1.16^(OVR-85) × 0.7     （OVR > 85，斜率放缓，封顶 3 亿）
```
验证：80 OVR 巅峰 ST 在英超 = 3600万 × 1.1 × 1.5 × 1.3 ≈ 7700 万欧，符合现实量级。

### 6.2 系数表

| 系数 | 取值 |
|------|------|
| 年龄 | 16岁×0.6 17岁×0.7 18岁×0.85 19-23×1.0 24-28×1.1 29-32×0.85 33+×0.6 |
| 位置 | ST×1.3 LW/RW×1.2 CAM/CM×1.15 CDM×1.0 CB×1.0 FB×0.9 GK×0.85 |
| 联赛 | 英超×1.5 西甲×1.4 德甲×1.3 意甲×1.25 法甲×1.15 荷甲×1.0 葡超×0.95 中超×0.7 |
| 合同 | 剩余≥3年×1.1 2年×1.0 1年×0.75 <1年×0.55 |
| 状态 | 0.85~1.2（进球/助攻/零封/金靴/最佳阵容加成；伤病或长期替补下调） |

### 6.3 年轻潜力溢价

18 岁以下且 OVR ≥ 70 的球员（含玩家）享受 ×1.5~3.0 潜力溢价，受硬约束封顶。

### 6.4 硬约束（引擎强制）

- 18 岁前：`OVR = min(OVR, 80)`；`身价 = min(身价, 80,000,000)`
- 身价每赛季末结算一次

## 12. 决策点系统（每赛季 8-10 个）

### 12.1 赛季骨架

```
① 夏窗（转会/续约/租借谈判） ② 季前备战（训练侧重） ③ 上半程 ×2-3
④ 冬窗（转会选择）           ⑤ 下半程 ×2-3        ⑥ 赛季末总结
```

### 12.2 事件类型库（decision.py，每类事件生成 3-4 个选项及合法效果）

| 类型 | 示例 |
|------|------|
| 比赛临场 | 单刀处理、任意球主罚权竞争、伤停补时定位球 |
| 训练 | 加练（速度/射门/体能）、新型训练法、恢复方案 |
| 人际关系 | 更衣室矛盾（站队/调解/沉默）、与主帅关系、外援队友 |
| 媒体 | 采访高调/低调/回避、社媒言论 |
| 伤病 | 保守复出 / 冒险复出 |
| 场外 | 饮食纪律、作息、应酬、理财 |
| 职业 | 位置转型、轮换定位、租借 vs 留队、违约金设置 |
| 国家队 | 落选心态、位置竞争、客场远征 |

### 12.3 决策骨架与效果结算

- `decision.py` 生成骨架：`{event, narrative_hooks, options:[{label, effects:{attr_delta, morale, form, injury_risk, reputation, value_factor}}]}`（效果为引擎预生成合法值）
- LLM 只接收骨架，输出文学化叙事与选项文案（**不允许改动 effects**，后端强制合并）
- 结算后可能连锁触发新事件（引擎检测条件）

## 14. LLM 叙事服务（narrator/）

### 14.1 配置（config.json，设置页填写）

```json
{
  "api_key": "sk-...",
  "base_url": "https://api.deepseek.com",   // OpenAI 兼容任意地址
  "model": "deepseek-chat"
}
```

- **未配置 API Key：游戏入口锁定**，主界面只显示设置页引导（`/api/setup/status` 返回未配置状态，前端强制跳转）
- 默认模型推荐 deepseek-chat；base_url/model 均可改

### 14.2 请求上下文（发给 LLM）

```
系统提示词：游戏规则（18岁前约束、属性体系、世界观、叙事风格"小说笔触、细腻"）
状态摘要：玩家档案摘要（属性/OVR/身价/合同/赛季数据/里程碑）
生涯历史：最近 N 节叙事摘要 + 关键事件队列（避免 LLM 失忆）
决策骨架：event + options（引擎生成。LLM 可见每个选项的**文学化因果提示**（如"拼抢激烈，可能受伤""加练速度，体能告急"），不可见具体数值；后端将骨架数值与 LLM 文案合并）
```

输出约束：**强制 JSON**（`{narrative, options:[{label, hint}]}`），后端 pydantic 校验；不合规重试 1 次，仍失败返回错误。

### 14.3 失败处理

- LLM 超时/限流 → 返回 502 + 前端提示"叙事生成失败，重试"，**绝不伪造叙事或数值**
- 上下文按需截断（token 预算：系统 1500 + 状态 800 + 历史 1200 + 输出 800，可配）

| 世界视图 | 当前联赛积分榜（升降级高亮）、所在球队战绩、欧战资格 |
| 转会流言板 | 引擎报价 + 真实新闻注入位，相关星标 |

刷新即最新（决策后自动刷新）；面板数据直接来自 `/api/game/state`。

## 16. REST API 协议

| 方法/路径 | 说明 |

## 17. 数据源

### 17.1 真实球员数据集（scripts/fetch_dataset.py，一次性）

- 来源：GitHub 开源 FIFA 数据集（CSV：OVR/位置/年龄/国籍/球队）
- 处理：下载 → 映射 16 联赛球队表 → 展开属性（OVR 前 500 球星读关键子属性，其余按位置模板展开）→ data/players.csv
- 失败降级：内置精简数据集（约 1500 人：每队主力+球星）

### 17.2 中文名映射（data/players_cn.csv）

- 中超及国足相关：约 200-300 人；五大联赛球星：约 500 人；其余英文名

## 18. 硬性约束与平衡规则（汇总）

1. 18 岁前 OVR ≤ 80，身价 ≤ 8000 万欧元（引擎强制）
2. 属性 0-99 整数；OVR 取整；身价取整到万欧
3. 年龄 <16 不进入职业队；16 岁从青训入营
4. 40 岁生日后首个赛季末触发退役抉择（之后每赛季末可再选）
5. 退役后开启教练生涯（每赛季 3-5 决策点）
6. 玩家 OVR 成长受 PA 约束（隐藏）
7. 每赛季 8-10 决策点；夏窗+冬窗必有决策
8. 中国球员国家队线完整模拟；外援政策简化不计入
9. **未配置 API Key 无法游玩**（硬性要求）

## 20. 风险与降级策略

| 风险 | 应对 |
|------|------|
| 数据集下载失败/过大 | 内置精简数据集（1500 人）兜底 |
| LLM 超时/限流/格式错误 | 重试 1 次 + 明确错误提示，绝不伪造叙事 |
| LLM 上下文失忆 | 生涯历史摘要队列 + 里程碑强制注入 |
| 用户 Key 额度耗尽 | 前端提示"API 额度不足"，引导换 Key |
| 中文名映射工作量大 | 只保证中超+国足+球星，其余英文名 |
| 世界模拟性能 | 向量化批量模拟，单赛季 <1 秒 |
| 玩家数值失控 | PA 约束 + 硬约束封顶 + 身价公式钳制 |
